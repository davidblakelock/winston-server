Please add a Settings panel to Winston that allows users to customize their experience at any time. Add a settings icon — gear or similar — in the header next to the user avatar. When clicked it opens a settings panel or modal with these four capabilities.
Setting 1 — Change companion voice: Show all six available voice options with their names and a play button next to each that plays a short sample saying Hello I have been looking forward to meeting you. The currently selected voice should be highlighted. When user selects a new voice save it immediately to their profile in Supabase and use it for all future responses. Emma Peel should confirm the change verbally in the new voice — something like How does this sound? I can be whoever you need me to be.
Setting 2 — Change companion name: Show a text input field with the current companion name. User can type any new name and click Save. Update the companion name everywhere in the app immediately — in the header, in greetings, in all responses. Save to Supabase. Emma Peel should acknowledge the change in her new name — for example if changed to James Bond she should say The name is Bond. James Bond. How can I help you?
Setting 3 — Profile photo from Google or initials: In the header avatar check if the user has a Google profile photo available from their OAuth login. If yes display it as a circular avatar. If no Google photo is available generate an avatar using the companion name initials — for example EP for Emma Peel or JB for James Bond. Use a warm colored background matching Winston's color scheme with white initials. This should update automatically when the companion name changes.
Setting 4 — Custom photo upload: In the settings panel add an Upload photo option. User can upload any image from their device — a photo of James Bond, a personal photo, anything they like. Store the uploaded image in Supabase storage. Display it as the avatar in the header replacing both the Google photo and initials fallback. The upload should accept jpg, png, and webp formats. Resize and crop to a circle automatically. Show a preview before saving.
The settings panel should be accessible at any time — not just during onboarding. Changes should take effect immediately without requiring a page reload. Save all changes to Supabase so they persist across devices and sessions. Make the settings panel feel warm and on brand — not like a generic settings menu.
