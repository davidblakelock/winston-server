Rename or replace the proactive_mode column with winston_mode in the user settings table
Valid values: 'autopilot', 'supervised', 'briefing_only'
Default: 'supervised'
Add a new table: trusted_senders with columns: id, user_id, email_or_domain, name, created_at
Migrate any existing proactive_mode data: whisper/vacation → briefing_only, balanced → supervised, full_partner → autopilot
2. New endpoints:

GET /api/settings/winston-mode — returns current mode
POST /api/settings/winston-mode — saves mode (autopilot, supervised, briefing_only)
GET /api/settings/trusted-senders — returns list of trusted senders
POST /api/settings/trusted-senders — adds a trusted sender { name, emailOrDomain }
DELETE /api/settings/trusted-senders/:id — removes a trusted sender
3. Autopilot mode behavior:
When winston_mode is 'autopilot':

Meeting requests from trusted senders → automatically accept, add to calendar, send acceptance reply via Gmail
Meeting requests from unknown senders → surface in morning briefing action buttons for user decision
Bills within normal range → track silently, no notification
Bill anomaly (>10% higher than usual) → immediate push notification
Package out for delivery → immediate push notification
Package delivered → immediate push notification
Flight change or cancellation → immediate push notification
Important email from VIP contact → immediate push notification with Claude summary
Promotional/spam email → silently filtered, never surfaces
Newsletter → summarized and held for morning briefing
Email needing reply from trusted sender → Claude drafts reply, sends automatically
Email needing reply from unknown sender → Claude drafts reply, surfaces in morning briefing action buttons
4. Supervised mode behavior:
When winston_mode is 'supervised':

Meeting requests → Claude prepares accept/decline recommendation, surfaces in morning briefing action buttons for user decision
Bills → track silently, surface anomalies in morning briefing
Package updates → push notification for out for delivery and delivered only
Flight changes → immediate push notification
Email needing reply → Claude drafts reply, surfaces in morning briefing action buttons
No automatic actions taken without user approval
5. Briefing Only mode behavior:
When winston_mode is 'briefing_only':

No proactive push notifications except: VIP contacts, package delivered, flight cancelled
Everything else held for morning briefing
Morning briefing is the only touchpoint
Email scanning runs every 2 hours
No automatic actions
