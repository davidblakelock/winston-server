Please build the onboarding backend. Read everything before starting.
1. POST /api/onboarding/complete
Accepts the following body and saves to the appropriate tables:
{
  firstName: string,
  lastName: string,
  wakeTime: string,
  city: string,
  hobbies: string[],
  musicGenres: string[],
  tvGenres: string[],
  sportsTeams: string,
  keyPeople: [{ name: string, relationship: string }],
  favoriteRestaurants: string,
  favoritePodcasts: string
}
Save to:

firstName, lastName, city, favoriteRestaurants, favoritePodcasts → user_profiles table
wakeTime → user_settings table (existing wake_time field)
hobbies, musicGenres, tvGenres, sportsTeams → user_profiles table as JSON columns (add if they don't exist)
keyPeople → key_people table (already exists) — create a record for each person
Set onboarding_complete = true in user_settings table

2. GET /api/onboarding/status
Returns current onboarding data for the user so the native app can pre-fill fields:
{
  isComplete: boolean,
  firstName: string,
  lastName: string,
  wakeTime: string,
  city: string,
  hobbies: string[],
  musicGenres: string[],
  tvGenres: string[],
  sportsTeams: string,
  keyPeople: [{ name: string, relationship: string }],
  favoriteRestaurants: string,
  favoritePodcasts: string
}
Deploy when complete and confirm both endpoints work with a test."
