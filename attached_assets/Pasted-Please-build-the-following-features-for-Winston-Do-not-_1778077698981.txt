3. Notification Intelligence
Build a notification triage system:
VIP system:

New table: notification_vips (user_name, contact_name, contact_phone, contact_email, created_at)
GET /api/settings/vip-contacts — returns VIP list
POST /api/settings/vip-contacts — adds a VIP contact
DELETE /api/settings/vip-contacts/:id — removes a VIP contact
VIP contacts always trigger immediate push notification regardless of mode

Hourly digest:

POST /api/notifications/digest — assembles and sends a smart digest push notification summarizing what came in since last digest
Digest respects proactive mode: Whisper sends digest every 4 hours, Balanced every 2 hours, Full Partner every hour, Vacation every 30 minutes
Digest notification is conversational not a list: 'Two things worth knowing: Susan texted asking what time you'll be home. Your Nordstrom order ships today.'

Focus mode:

POST /api/settings/focus-mode — enables focus mode with optional duration in minutes
During focus mode: only VIPs get through, everything else held for end-of-focus digest
When focus mode ends: send digest of everything that came in during focus period
GET /api/settings/focus-mode — returns current focus mode status

SMS triage (if Android SMS read access is available via API):

Read incoming SMS
Match sender against contacts and VIP list
VIP SMS triggers immediate push notification
Non-VIP SMS held for hourly digest
POST /api/sms/digest — returns SMS summary for digest
